# 01 — Project Setup, Convex Schema & Convex Auth

**What to build:**
Initialize the Next.js App Router application with Tailwind CSS (Dark Mode FinTech theme), setup Convex as the backend database, configure Convex Auth for user registration/login, and define the core database schema (users, accounts, assets, transactions, monthly_snapshots).

**Blocked by:** None — can start immediately.

**Status:** completed

## Acceptance Criteria

- [x] Next.js App Router project initialized with TypeScript and Tailwind CSS.
- [x] Convex backend initialized with schema (`users`, `accounts`, `assets`, `transactions`, `monthly_snapshots`).
- [x] Convex Auth configured for email/password or magic link authentication.
- [x] Mobile-first base layout with Dark FinTech glassmorphism styling created.
- [x] User authentication flow working (login/logout screens).
