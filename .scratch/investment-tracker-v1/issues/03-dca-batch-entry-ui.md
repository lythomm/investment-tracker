# 03 — Fast DCA Batch Entry Form UI & Single Entry Modal

**What to build:**
Build a mobile-first responsive UI featuring a multi-line "DCA du Mois" batch entry form allowing users to log multiple asset purchases in a single submission in under 30 seconds, plus a single transaction modal for isolated additions or sales.

**Blocked by:** 02 — Account Management & Asset Ledger Backend

**Status:** completed

## Acceptance Criteria

- [x] "DCA du Mois" batch entry component allowing adding N lines (Account, Asset, Quantity, Price, Fees) with a single submit.
- [x] Single transaction form modal for one-off transactions (Achat, Vente, Dividende).
- [x] Responsive UI optimized for mobile touch targets and quick input.
- [x] Instant reactive update of transaction list upon submission.
